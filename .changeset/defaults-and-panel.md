New default values. The theme color is `#fad30b`, the motion is `full` and the maximum pixel ratio is 1.5. The cloud, chalk and glitter effects have new defaults. To obey `prefers-reduced-motion`, set `theme.motion` to `auto`.

The panel plugin has the option `closable`. The script tag build accepts the attributes `data-wand-panel`, `data-wand-panel-container` and `data-wand-panel-expanded`.
