A wand for your pointer.

Chalk strokes, glitter and soft clouds that follow the pointer. One small library with no dependencies.

Read the docs

Two lines to start.

npm i magic-cursor-wand

import { createWand } from 'magic-cursor-wand';
createWand();

Change everything, keep the core.

Every value is a setting.

Chalk size, smoothing, taper, gravity, twinkle and cloud density. Push Alt Shift W and move the sliders while you draw.

Settings from anywhere.

Read them from localStorage, an HTTP endpoint or a server event stream. Changes save automatically.

Your own effects.

Effects, plugins and providers are small objects. Add one without a change to the core.
