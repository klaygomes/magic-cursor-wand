Chalk, glitter and clouds for your pointer.

Move the pointer to make clouds. Push the button and move the pointer to draw with chalk. Release the button to see the chalk change into glitter.

Get started npm i magic-cursor-wand

  1. Move

    Clouds follow the pointer and go up slowly.

  2. Draw

    Push the button and move. The chalk line has soft edges and thin tips.

  3. Release

    The line fades and changes into glitter. Push Alt+Shift+W to change the settings.
