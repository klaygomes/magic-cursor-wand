magic-cursor-wand Overlay Container Script tag Docs GitHub

One script tag.

No bundler. The data attributes start the wand, and the integrity hash protects the file.

<script
    src="https://cdn.jsdelivr.net/npm/magic-cursor-wand@0.2.0/dist/magic-cursor-wand.iife.js"
    integrity="sha384-XxBXqYPuFEcQp51OYVOK/CslqB4ooezSzEvohIGISSD4E7Gxi3IOg09R3e/wKmF5"
    crossorigin="anonymous"
    data-wand-storage-key="my-site-wand"
    data-wand-cursor="replace"
    data-wand-panel-hotkey="Alt+Shift+W"
  ></script>
data-wand-config-url
Loads settings from an HTTP endpoint.
data-wand-storage-key
Keeps the settings of each visitor in localStorage.
data-wand-cursor
Adds the cursor: glow or replace.
data-wand-panel-hotkey
Opens the settings panel with this shortcut.
