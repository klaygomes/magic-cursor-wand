Script tag build.

This page loads magic-cursor-wand.iife.js with one script element. The data-wand-* attributes start the wand. No bundler is necessary.

  1. Add the script

    Load the file from jsDelivr or unpkg.

  2. Add the attributes

    Set data-wand-config-url, data-wand-storage-key and data-wand-cursor.

  3. Open the settings

    Push Alt+Shift+W. The panel loads Tweakpane from the CDN.
